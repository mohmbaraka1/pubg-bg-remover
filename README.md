# GS Studio — منصة تصميم احترافية لتجار حسابات PUBG Mobile

موقع كامل (فرونت اند + باك إند) يخلّي تاجر/بائع حساب PUBG Mobile يطلع بصورة
عرض احترافية لحسابه خلال دقايق — من سكرين شوت عادي، بدون ما يفتح فوتوشوب
ولا يحتاج مصمم.

**الموقع منشور فعلياً:** https://pubg-bg-remover.vercel.app

---

## الفكرة بجملتين

تصميم صورة عرض احترافية لحساب PUBG Mobile يدوياً (فوتوشوب) بياخذ من 5 دقايق
(حساب صغير) لساعتين (حساب كبير فيه عشرات العناصر). المنصة هاي بتنزّل هالوقت
لأقل من 10 دقايق — عبر إزالة خلفية بالذكاء الاصطناعي + قوالب تصميم جاهزة
(مبنية فعلياً من تصاميم محترفين حقيقيين) تتبدّل عناصرها بضغطة زر.

## الميزات الفعلية (الحالة الحقيقية اليوم، مو خطة مستقبلية)

### للمستخدم العادي
- **إزالة خلفية بالذكاء الاصطناعي** — يرفع سكرين شوت من داخل اللعبة، والنظام
  يفصل الشخصية (بالسلاح والملابس) عن الخلفية تلقائياً بدقة عالية. يدعم
  استخراج شخصية وحدة أو عدة شخصيات من نفس الصورة دفعة وحدة.
- **Design Studio** — يفتح قالب جاهز، يستبدل كل خانة (شخصية/سلاح/مركبة/
  إطار...) بعناصره من مكتبته الخاصة أو من مكتبة الموقع، مع خطوط محاذاة ذكية
  (Smart Guides) وتصدير PNG نهائي بضغطة زر.
- **Image Editor / Magic Crop** — أدوات تحرير إضافية على الصورة النهائية.
- **مكتبة قوالب (Template Library)** — تصفح كل القوالب الجاهزة واختيار
  المناسب.
- **حسابات متعددة، سجل، مفضّلة، ترقية للباقة المدفوعة** — إدارة كاملة
  لعمل التاجر اليومي.

### أدوات الإدارة (Admin/Designer - داخلية، تبني المحتوى يلي يستخدمه الزبون)
- **Template Editor** — بناء التيمبلتات بـ3 طرق:
  1. يدوي: سحب/تحجيم كل خانة على Canvas.
  2. توليد تلقائي بالعدد: تحديد عدد الشخصيات/الأسلحة/الإطارات وترتيبهم
     تلقائياً.
  3. **استيراد صورة مرجعية**: يرفع تصميم احترافي حقيقي، والنظام يكتشف
     تلقائياً مكان كل شخصية (نموذج ذكاء اصطناعي) + شبكات الأسلحة/السيارات
     (خوارزمية دورية/periodicity مبنية خصيصاً - دقة عالية حتى مع فواصل
     خافتة جداً بين الأيقونات).
  - كل خانة تُعرض **بشكلها الحقيقي** (صورة فعلية) بدل مربع لون عام، وفيها
    **حفظ تلقائي محلي** (draft autosave) ما يخلي الشغل يضيع لو صار تنقّل
    عرضي بين الصفحات.
  - كل تيمبلت يترفق تلقائياً بـ: عدد كل نوع عنصر، فئة (Category)، وسوم
    ستايل، وعدّاد شعبية (usage_count) يزيد أوتوماتيكياً كل مرة يُصدَّر تصميم
    مبني عليه — أساس تصنيف/ترتيب تلقائي للقوالب مستقبلاً حسب الاستخدام
    الفعلي.
- **Grid Extractor** — رفع سكرين شوت وتحديد مستطيل (أو أكتر) حوله، والنظام:
  - يقص شبكة أيقونات منتظمة (أسلحة/سيارات) لعناصر منفصلة دقيقة.
  - أو (وضع "تفريغ عنصر مفرد") يفرّغ عنصر مفرد (إطار، شعار/هاشتاق) بالكامل
    من خلفيته الفوتوغرافية ويرجّعه بخلفية شفافة.
- **Game Library** — مكتبة عناصر جاهزة (أسلحة، مركبات، خوذات، إطارات...)
  مصنّفة، يقدر يرفعلها الأدمن أو مصمم مصرّح له صلاحية محدودة.
- **نظام صلاحيات (Roles)** — أدمن كامل، أو "مصمم" بصلاحية محدودة (رفع
  للمكتبة بس، بدون وصول لـTemplate Editor أو Grid Extractor).

## التقنية

### Frontend
React 18 + Vite + Tailwind CSS + Konva (محرر Canvas تفاعلي) + React Router +
Supabase JS. منشور على **Vercel**.

### Backend
FastAPI (Python) + خط أنابيب ذكاء اصطناعي:
**YOLOX** (تحديد موضع الأشخاص) → **SAM2** (قناع دقيق للجسم) → **BiRefNet**
(تنعيم الحواف/التفاصيل الدقيقة) → دمج وتصدير PNG شفاف.

> ⚠️ **الباك إند لسا مش منشور بأي استضافة دائمة عامة** — يشتغل محلياً/عبر
> Docker حالياً (انظر [DEPLOYMENT.md](DEPLOYMENT.md)). ميزة إزالة الخلفية
> بالذكاء الاصطناعي وGrid Extractor ما رح تشتغل على الرابط المنشور لحد ما
> يُنشر الباك إند على سيرفر حقيقي.

### قاعدة البيانات والتخزين
**Supabase** (Postgres + Auth + Storage) — جداول التيمبلتات، المكتبة،
الحسابات، الأدوار، كلها هناك.

### الرخص (مهم لأي بيع/استثمار)
كل نموذج ذكاء اصطناعي مستخدم **مرخّص لاستخدام تجاري مغلق المصدر بدون قيود**:
- YOLOX — Apache-2.0 (مُضمَّن كود مصدره مباشرة بـ`backend/app/vendor/yolox`،
  بدل ultralytics/YOLOv8 اللي كانت AGPL-3.0 وتفرض نشر كل كود المشروع لأي
  خدمة SaaS تستخدمها).
- SAM2 (Meta) — Apache-2.0.
- BiRefNet — MIT.

## نقاط API (Backend)

| Endpoint | الوظيفة |
|---|---|
| `POST /api/remove-background` | إزالة خلفية شخصية وحدة |
| `POST /api/remove-background-multi` | إزالة خلفية عدة شخصيات بصورة وحدة |
| `POST /api/remove-background/prepare` + `/tune` | تعديل تفاعلي سريع (بدون إعادة تشغيل النماذج الثقيلة) |
| `POST /api/detect-full-layout` | استيراد صورة مرجعية → كشف شامل (شخصيات + شبكات) لبناء تيمبلت |
| `POST /api/detect-people` | كشف مواضع الأشخاص فقط (سريع) |
| `POST /api/grid-slice` | قص شبكة أيقونات منتظمة داخل مستطيل محدد |
| `POST /api/extract-cutout` | تفريغ عنصر مفرد (إطار/شعار) من خلفيته |
| `POST /api/upscale` | تكبير صورة بالذكاء الاصطناعي |
| `GET /api/health` | فحص حالة السيرفر |

## التشغيل محلياً

### الطريقة الأسهل: Docker
```bash
cp .env.example .env   # وحط قيم Supabase الحقيقية
docker compose up --build
```
يفتح على `http://localhost:8080`. التفاصيل الكاملة (بما فيها خيارات
الاستضافة الحقيقية للفرونت/الباك إند) بملف [DEPLOYMENT.md](DEPLOYMENT.md).

### يدوي — Backend
```bash
cd backend
python -m venv venv
venv\Scripts\activate          # Windows
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
أول طلب فعلي بيحمّل أوزان YOLOX + SAM2 + BiRefNet تلقائياً (مرة وحدة، عدة
جيجابايت، تحتاج إنترنت).

### يدوي — Frontend
```bash
cd frontend
npm install
npm run dev
```
افتح `http://localhost:5173`. ملف `.env` (انسخه من `.env.example`) لازم
فيه `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY`.

## الخطوة الجاية (Roadmap)

البنية التحتية للـ**Smart Template Engine** جاهزة (تصنيف تلقائي + عدّادات
+ تتبّع شعبية لكل تيمبلت) — الخطوة الجاية: مكتبة ٥٠ تيمبلت احترافي حقيقي،
ومحرك مطابقة يقترح أفضل ٣ تيمبلتات تلقائياً حسب العناصر يلي يختارها
المستخدم (بدل التصفح اليدوي).
