# PUBG Character Background Remover — المرحلة الأولى فقط

نظام لاستخراج الشخصية الرئيسية من سكرين شوت PUBG Mobile كاملة (من الرأس للقدم،
مع السلاح إن وُجد) وإزالة الخلفية بالكامل، وإخراج PNG بخلفية شفافة.

خط الأنابيب: **YOLOv8** (تحديد موضع الشخصية) → **SAM2** (قناع دقيق للجسم) →
**BiRefNet** (تنعيم الحواف والتفاصيل الدقيقة) → دمج وتصدير PNG شفاف.

> لا يوجد في هذه المرحلة: تسجيل دخول، قاعدة بيانات، قوالب، أو أي صفحة غير
> صفحة "Background Remover" الواحدة.

---

## المتطلبات

- Python 3.10+ (يُفضّل بيئة بها GPU + CUDA لتسريع الاستنتاج، لكنه يعمل على CPU أيضاً — أبطأ فقط)
- Node.js 18+
- اتصال إنترنت عند أول تشغيل (لتحميل أوزان YOLOv8 + SAM2 + BiRefNet تلقائياً، حجمها الإجمالي عدة جيجابايت تقريباً)

## 1) تشغيل الـ Backend

```bash
cd backend
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
# source venv/bin/activate

pip install -r requirements.txt

uvicorn app.main:app --reload --port 8000
```

عند أول طلب فعلي على `/api/remove-background`، سيتم تحميل أوزان SAM2 و BiRefNet
و YOLOv8 تلقائياً (مرة واحدة فقط، تُحفظ محلياً بعدها). راقب الـ terminal لمتابعة
تقدم التحميل.

تحقق أن السيرفر يعمل:
```
GET http://127.0.0.1:8000/api/health  ->  {"status": "ok"}
```

## ملاحظات تقنية مهمة

1. **لماذا YOLOv8 + SAM2 معاً وليس SAM2 وحده؟**
   SAM2 يحتاج "prompt" (نقطة أو صندوق) ليعرف أي عنصر في الصورة يريد تقطيعه.
   YOLOv8 يحدد تلقائياً صندوق "الشخصية الرئيسية" (الأكبر والأقرب لمركز
   الصورة، وهو النمط المعتاد في شاشات PUBG) ليُستخدم كـ prompt لـ SAM2 —
   هذا ما يجعل الاكتشاف تلقائياً بالكامل دون تدخل يدوي.

2. **لماذا BiRefNet بعد SAM2؟**
   قناع SAM2 دقيق تشريحياً لكنه أحياناً "خشن" عند حواف الشعر أو تفاصيل
   السلاح الدقيقة. BiRefNet نموذج matting متخصص في استخراج حواف عالية
   الدقة، فنُدمج الاثنين: SAM2 يضبط "أين الشخصية"، و BiRefNet يضبط
   "جودة الحافة".

3. **الأداء:** أول تشغيل بعد إقلاع السيرفر سيكون أبطأ (تحميل النماذج على
   الذاكرة). الطلبات التالية أسرع بكثير لأن النماذج تبقى محمّلة (singleton
   في `pipeline.py`).

4. **CPU vs GPU:** يعمل المشروع على CPU لكن المعالجة قد تأخذ من 20 إلى 60
   ثانية للصورة الواحدة حسب دقتها. على GPU متوسط، عادة أقل من 5 ثوانٍ.
